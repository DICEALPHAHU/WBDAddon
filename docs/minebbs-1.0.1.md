# 【1.0.1 更新】新增防第三人称与拆弹声音提示

> WarZBombDefuse 的第三方附加组件合集
> 每个功能都是独立模块，`config.yml` 单独开关，互不影响，无需改动 WBD 本体

---

## ⚠️ 先说重点：本次新增一个依赖

**「防第三人称」模块需要 [ProtocolLib](https://hangar.papermc.io/dmulloy2/ProtocolLib/versions)。**

如果你在 **Arclight / Spigot** 上开服，请务必装上，否则这个模块会**自动禁用**。

为什么非得要它？防第三人称的原理是给玩家挂一块「只对本人可见」的遮挡面，而「只对本人可见」这件事，Arclight 上**用 Bukkit 自带的方法做不到**——那些方法签名都在、调用也不报错，就是一点效果都没有，结果遮挡面会挂在**所有人**身上（玩起来就是「黑块糊在对手脸上还跟着跑」）。

所以改成在数据包层拦截：你装了 ProtocolLib，插件就能把遮挡面的实体包**只发给本人**，别人客户端根本收不到这个实体。

**不装会怎样？** 不会报错、不会崩、也不会有黑块——插件会主动检测并**直接禁用这个模块**，其它模块照常工作。

> 如果你用 **Paper / Folia**，那边的隐藏 API 是真有效的，可以不装 ProtocolLib，只需把配置里的 `require-protocol-lib` 设为 `false`。

## ✨ 新增模块

### 1. 防第三人称偷看（`antithirdcam`）

有些玩家会切第三人称隔着掩体偷看。第三人称是**纯客户端按键**，服务端既禁不掉也侦测不到，所以这里换个思路——**遮挡**：

- 给参赛玩家挂一块巨大的黑色遮挡面，**只对该玩家本人可见**
- 切到第三人称时视野被糊住，隔墙偷看就失去意义了
- 只在竞技场内对**参赛且仍存活**的玩家生效；观战者、大厅玩家、本回合已阵亡的人都不受影响
- 遮挡面每 tick 主动跟随玩家，不改变玩家自身的任何状态

> 实现思路参考开源插件 [AntiF5](https://github.com/ladakx/AntiF5)

### 2. 拆弹声音提示（`bomb-defuse-sound`）

**WBD 本体在「开始拆弹」和整个拆弹过程中是完全静音的**——它只在拆除成功（`bomb-defused`）和进度被中断（`cancel`）时才有音效。结果就是 CT 蹲下去拆弹，T 阵营一点动静都听不到，等于没有博弈信息。

本模块补上这一段：

- CT 开始拆弹时，在 **C4 所在位置**播放一声提示音，随后按固定间隔持续播放滴答声
- 声音以 C4 为音源，**带方位与距离衰减**——T 能听出「有人在拆」以及「大概在哪个方向」，而不是只收到一句广播
- 默认可听范围约 **32 格**（音量可调，17 音量约等于 256 格）
- 音效可以换，默认用 `BLOCK_NOTE_BLOCK_BIT`（8-bit 芯片音色）做电子「嘀嘀嘀」
- 中断音与成功音默认**留空**，因为 WBD 本体已经有了，避免重复出声

## 🎨 其他改进

**比赛状态新增「方块串」存活样式**

除了原来的数字样式（`T 存活 3/5`），现在可以切换成方块串，每人一个方块、用亮色/暗色区分存活与淘汰，一眼看清还剩几个人：

```yaml
modules:
  match-status:
    alive-display-style: block
```

**新增两个命令**

| 命令 | 作用 |
| --- | --- |
| `/wbdaddon sound <音效名> [音调]` | 试听拆弹提示音（连播三次），不带参数会列出推荐音效清单 |
| `/wbdaddon diag` | 环境诊断：列出你服务端有哪些 API 可用、ProtocolLib 是否就位 |

挑音效原来只能真去拆一次弹才听得到，现在直接试听就行。

## 🐛 修复

- **防第三人称的黑块泄漏**：此前遮挡面对所有人可见（就是上面说的「黑块糊脸」），已改为 ProtocolLib 数据包层拦截
- **缺少依赖时不再留下副作用**：检测不到 ProtocolLib 时直接禁用该模块，而不是半死不活地跑着
- **比赛状态**：清理离场玩家残留的 BossBar 与过期的炸弹计时记录，避免长时间运行后内存缓慢增长
- **构建产物**：文件名带上版本号 + git 短哈希 + 构建时间戳，多次构建不会互相覆盖

## 📦 升级步骤

1. 删掉 `plugins/` 里旧的 `WBDAddon-*.jar`（**文件名不认，Bukkit 只认插件名，留着多个会冲突**）
2. 放入新的 `WBDAddon-1.0.1-xxxxxxx-xxxxxxxx-xxxx.jar`
3. 需要防第三人称的话，把 **ProtocolLib 5.4.0** 也放进 `plugins/`
4. 重启服务器，或执行 `/wbdaddon reload`

装好后启动日志里应该能看到这两行：

```
遮挡面已改用 ProtocolLib 在数据包层隐藏，只对本人可见。
[WBDAddon] 防第三人称已启动，检查间隔 20 tick，跟随方式 teleport。
```

> 旧版配置文件不会自动补上新配置项，建议对照新版 `config.yml` 手动合并，或删掉重新生成。

## ⚠️ 一个已知问题（属于 WBD 本体，不是本插件）

在 **Arclight** 上，WarZBombDefuse 的**回合出生点传送会失败**，控制台会刷：

```
玩家 xxx 回合出生点传送未生效，正在重试。
传送失败。原因=round-spawn-retry
错误='java.util.concurrent.CompletableFuture org.bukkit.entity.Player.teleportAsync(org.bukkit.Location)'
```

原因是 WBD 用了 `Player#teleportAsync`，而这是 **Paper / Folia 专属 API**，Arclight 上没有这个方法。表现为**每回合双方位置都不重置**。

这个只能由 WBD 作者修（它内部已经有 `isFolia()` 这类环境判断，只是传送这一处漏了）。建议遇到时向作者反馈一句：*非 Folia 环境下请退回 `player.teleport(Location)`*。
